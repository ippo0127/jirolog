# はじめての二郎

> ルールは店ごとに少しずつ違います。ここに書いたのは多くの直系店に共通する流れです。迷ったら前の人の動きを見て、張り紙と店員さんの指示に従ってください。各店のページにある「この店のルール」も見ておくと安心です。

## 1. 行く店と時間を決める

- [店舗一覧](stores/index.html)の営業時間は目安です。麺がなくなると予定より早く終わることがあります（列を締め切ることを「宣告」といいます）。
- 臨時休業や時間の変更は、店の公式 X で知らせることが多いので、出かける前に確認しましょう。
- 並びの長さは店と時間帯でかなり変わります。昼の開店前後と夜のピークは長くなりやすいです。

## 2. 並ぶ

- 並ぶ場所は店ごとに決まっています。壁沿いに並ぶ、車道に出ない、隣の店の前を空ける、など。張り紙を確認します。
- 連れがいる場合は、全員そろってから並ぶのが基本です。後から列に合流するのはやめましょう。
- 列の途中で先に食券を買う店もあります。前の人に合わせれば大丈夫です。

## 3. 食券を買う

- 一番基本のメニューは **小ラーメン** です。小でも麺の量は一般的なラーメン店の2倍前後ある店が多く、初めてなら小で十分です。
- **豚入り**・**豚ダブル** はチャーシュー（二郎では「豚」）の増量です。豚なしの小でも、厚い豚が乗ってきます。
- **大** はかなりの量です。食べきれる量を選びましょう。
- 券売機は現金だけの店が多く、使えないお札がある機械もあります。千円札と小銭があると安心です。

## 4. 席に着いて食券を置く

- 席に案内されたら、食券をカウンターの上の台に置きます。
- 麺を減らしたいときは、食券を置くときや店員さんに聞かれたときに「麺少なめ」「麺半分」と伝えます。
- 水はセルフの店が多いです。

## 5. コール（無料トッピングを伝える）

- ラーメンができる直前に、店員さんが「ニンニク入れますか？」と聞きます。これが合図です。聞かれる前に自分から言わないようにしましょう。
- 答えるのは無料トッピングの希望です。例: 「ヤサイニンニクアブラ」「ニンニクすこし」。何もいらなければ「そのままで」。
- 主なトッピングは **ヤサイ**（茹でたもやしとキャベツ）、**ニンニク**（刻みにんにく）、**アブラ**（背脂）、**カラメ**（タレを足して味を濃く）。店によっては生姜などもあります。
- 「マシ」は増量、「マシマシ」はさらに増量です。マシマシを受け付けない店もあるので、初めてならマシまでにしておくのが無難です。
- 食券を置いた時点でトッピングを聞く店もあります。くわしくは[用語集](glossary.html)へ。

## 6. 食べる

- 丼が届いたら、すぐに食べ始めます。同じロット（まとめて作られた数杯）の人と同じくらいに食べ終えるのが理想です。
- ヤサイが多いときは、下の麺を引き出して上に返す「天地返し」をすると、麺がのびにくくなります。
- 写真は手早く。料理以外の撮影や動画を禁止している店もあります。
- 食べている間の電話や長話は控えましょう。

## 7. 食べ終わったら

- 丼をカウンターの上の台に戻し、備え付けのダスターでカウンターを拭く店が多いです。
- 「ごちそうさまでした」と言って、すぐに席を立ちます。

## よくある質問

**量が心配** :: 食券を置くときに「麺少なめ」「麺半分」と伝えましょう。ほとんどの店で通じます。
**一人でも大丈夫？** :: カウンターだけの店がほとんどなので、一人の客が大半です。
**持ち帰りはできる？** :: 豚や麺を持ち帰りで売っている店もあります。店ごとの告知を確認してください。
**行った店を記録したい** :: [マイ二郎ログ](log.html)で、食べた日とメニュー、コールを記録できます。
