# 二郎用語集

二郎でよく使われる言葉です。呼び方や扱いは店によって違うことがあります。

## お店のこと

直系 :: 「ラーメン二郎」の名前で営業している店。三田本店の流れをくむ店で、のれん分けで開いた店が多い。
インスパイア（二郎系） :: 二郎に影響を受けた別の店。「ラーメン二郎」は名乗らない。
三田本店 :: すべての直系の本家にあたる店。東京・三田の慶應義塾大学の近く。
総帥 :: 三田本店の店主・山田拓美さんの愛称。
助手 :: 店主と一緒に厨房に立つ店員。
ジロリアン :: 二郎の熱心なファン。
黄色い看板 :: 多くの直系店の目印。

## 注文と量

小 / 大 :: 麺の量。小でも一般的な店の2倍前後あることが多い。
豚 :: チャーシューのこと。「豚入り」「豚ダブル」は豚の増量。
麺少なめ / 麺半分 :: 麺を減らす頼み方。食券を置くときや聞かれたときに伝える。
汁なし :: スープが少なく、タレと麺をからめて食べるメニュー。出している店は一部。
つけ麺 :: 季節限定などで出す店がある。
生卵 :: 別売りの店があり、すき焼きのように麺をくぐらせて食べる。
持ち帰り豚 :: 豚のかたまりを持ち帰りで売る店がある。「豚一本」と呼ばれることも。

## コール

コール :: 無料トッピングの希望を伝えること。店員さんの「ニンニク入れますか？」が合図。
ニンニク :: 刻んだ生のにんにく。
ヤサイ :: 茹でたもやしとキャベツ。
アブラ :: 背脂。
カラメ :: カエシ（タレ）を足して味を濃くすること。
マシ :: トッピングの増量。「ヤサイマシ」など。
マシマシ :: マシよりさらに増量。受け付けない店もある。
全マシ :: ヤサイ・ニンニク・アブラ・カラメをすべてマシにすること。
すこし / 抜き :: 減らす、入れない。「ニンニクすこし」「ヤサイ抜き」など。
そのままで :: トッピングをどれも足さないときの答え方。

## 食べ方と店内

ロット :: まとめて茹でて作られる数杯のひとまとまり。同じロットの人と同じくらいに食べ終えるのが理想。
ロットを乱す :: 食べるのが遅すぎるなどで、店の回転を止めてしまうこと。
天地返し :: 下の麺を引き出して上のヤサイと入れ替えること。麺がのびにくくなる。
乳化 / 非乳化 :: スープの状態。脂と水分が混ざって白っぽく濁ったものが乳化、醤油の色が強く澄んだものが非乳化。同じ店でも日によって変わる。
宣告 :: その日の列を締め切ること。最後の人に札を渡したりして知らせる。
麺切れ :: 麺がなくなり、その日の営業が終わること。

## 材料

カエシ :: 醤油などを合わせて作るラーメンのタレ。丼に入れてスープで割る。二郎のカエシには豚の旨みも溶け込んでいる。
カネシ :: 二郎のカエシのもとになる醤油の通称。もとは販売元の社名から来た呼び名で、カエシそのものとは別の言葉。
カチョウ（化調） :: 化学調味料の略で、うま味調味料（グルタミン酸ナトリウム）のこと。「グル」とも。二郎ではカエシと一緒に丼に入れる、味の要のひとつ。
オーション :: 二郎の麺に使われることで知られる強力粉の銘柄。
